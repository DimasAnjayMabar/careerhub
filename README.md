# How to initiate this dummy program
1. Please initiate venv on each frontend and frontend2 folder
2. Install python dependency on each folder using requirements.txt
3. To run program, make sure to enter the right folder
4. If your destination is Topic 7, please visit frontend folder
5. If your destination is Topic 9, Please visit frontend2 folder
6. run this command then open your browser using localhost generated by streamlit: 
```bash
streamlit run index.py
```
